# Dataset

The complete supplied SEM image dataset is distributed as independent Release ZIP archives because it is too large for a practical Git checkout.

The original folder contains **16,636 files** supplied through these [Release downloads](https://github.com/ArviZuko/AI-Based-EM-Image-Restoration/releases/tag/v1.0-project-files):

- [dataset-part-01-of-06.zip](https://github.com/ArviZuko/AI-Based-EM-Image-Restoration/releases/download/v1.0-project-files/dataset-part-01-of-06.zip) — 2,356 files under this directory.
- [dataset-part-02-of-06.zip](https://github.com/ArviZuko/AI-Based-EM-Image-Restoration/releases/download/v1.0-project-files/dataset-part-02-of-06.zip) — 2,316 files under this directory.
- [dataset-part-03-of-06.zip](https://github.com/ArviZuko/AI-Based-EM-Image-Restoration/releases/download/v1.0-project-files/dataset-part-03-of-06.zip) — 2,464 files under this directory.
- [dataset-part-04-of-06.zip](https://github.com/ArviZuko/AI-Based-EM-Image-Restoration/releases/download/v1.0-project-files/dataset-part-04-of-06.zip) — 2,686 files under this directory.
- [dataset-part-05-of-06.zip](https://github.com/ArviZuko/AI-Based-EM-Image-Restoration/releases/download/v1.0-project-files/dataset-part-05-of-06.zip) — 2,707 files under this directory.
- [dataset-part-06-of-06.zip](https://github.com/ArviZuko/AI-Based-EM-Image-Restoration/releases/download/v1.0-project-files/dataset-part-06-of-06.zip) — 4,107 files under this directory.

Download the listed ZIP files and extract them at the **repository root**. Each archive stores the original path, so the files land in this directory automatically.

The dataset ZIP files are independent; download every archive listed here to restore this folder completely.
