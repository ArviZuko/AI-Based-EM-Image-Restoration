This directory preserves the supplied restoration dataset, train split, combined degradation group.

- [dataset-part-01-of-06.zip](https://github.com/ArviZuko/AI-Based-EM-Image-Restoration/releases/download/v1.0-project-files/dataset-part-01-of-06.zip) — 1,520 files under this directory.
- [dataset-part-02-of-06.zip](https://github.com/ArviZuko/AI-Based-EM-Image-Restoration/releases/download/v1.0-project-files/dataset-part-02-of-06.zip) — 1,390 files under this directory.

Download the listed ZIP files and extract them at the **repository root**. Each archive stores the original path, so the files land in this directory automatically.

The dataset ZIP files are independent; download every archive listed here to restore this folder completely.
